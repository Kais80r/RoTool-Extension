# RoTool icon sources

The RoTool mark combines and adapts these MIT-licensed Iconify glyphs:

- `bxl:roblox` from Boxicons: <https://icon-sets.iconify.design/bxl/roblox/>
- `ion:hammer` from Ionicons: <https://icon-sets.iconify.design/ion/hammer/>

The combined composition, colors, and generated PNG sizes are stored locally in this extension. No icon is loaded from the network at runtime.

The Random Server control adapts `uil:server` from Unicons by Iconscout (Apache-2.0): <https://icon-sets.iconify.design/uil/server/>. Its foreground die and three-tier composition are original to RoTool. The combined SVG is embedded locally and is never downloaded at runtime.
